# AI RPG — Magic System Specification

## Obiettivo
La magia è un sistema esteso e persistente. Il personaggio conserva tutte le magie realmente apprese, organizzate per categorie ma senza un elenco chiuso obbligatorio.

## Categorie iniziali
- Fuoco
- Acqua
- Aria/Vento
- Terra
- Ghiaccio
- Fulmine
- Luce
- Oscurità
- Vita/Guarigione
- Morte/Negromanzia
- Natura
- Metallo
- Spazio
- Tempo
- Telecinesi
- Illusione
- Evocazione
- Barriere/Protezione
- Potenziamento
- Maledizioni
- Purificazione
- Spirituale
- Mentale
- Dimensionale
- Sangue
- Arcana
- Altre categorie possono essere aggiunte dal mondo.

## Magie
Una magia è un'entità persistente con dati flessibili. I campi possibili comprendono nome, categoria, descrizione, effetto, difficoltà/livello, costo, condizioni, padronanza, origine/apprendimento, limitazioni e varianti.

## Regole
- Non tutte le magie hanno gli stessi campi.
- Una magia può evolvere o avere varianti.
- Il personaggio può conoscere una categoria senza padroneggiarne tutte le magie.
- L'apprendimento deve avere una causa coerente: studio, pratica, insegnamento, esperienza, scoperta, oggetto, evento o altra causa valida.
- Il motore valida l'apprendimento e lo stato; l'IA interpreta e descrive ciò che accade.
- Le magie non devono essere generate casualmente solo per riempire la scheda.
